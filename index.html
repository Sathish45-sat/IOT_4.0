How to Modify or Add Questions

This practice portal is designed to be 100% frontend and effortlessly customizable. All questions are neatly organized inside the questions.js file.

Adding a New Week / Assignment:

Simply open questions.js and add a new entry to the assignmentsData object:

"week3": { id: "week3", title: "Week 03 : Assignment 03", topic: "Topic Title Here", questions: [ { id: 1, question: "Your question text here...", options: ["Option A", "Option B", "Option C", "Option D"], correctIndex: 1, // 0 for A, 1 for B, 2 for C, 3 for D explanation: "Detailed explanation to display when answered." } ] }

Key Highlights:

  • Instant visual feedback: Green for correct, Red for incorrect with automatic highlighting of the correct answer.
  • Quick Navigation: Jump to any question instantly via the top palette.
  • Comprehensive Review: View questions by status (All, Incorrect, Correct) at the end.
  • Offline & Local: Double-click index.html to run anywhere in any browser.
